Uploading the new website to GoDaddy

  1. Sign in at godaddy.com → My Products → Web Hosting → cPanel Admin.
  2. Open File Manager → go to public_html.
  3. Back up first: select all → Compress → download the zip.
  4. Click Upload and choose maasinspiration_upload.zip (ask Grok Bot to send it to you).
  5. Right-click the zip → Extract into public_html → allow it to replace files.
  6. Open maasinspiration.org, refresh, and check Home, Donate, and Volunteer.

The website is frozen. Nothing changes until you ask.
